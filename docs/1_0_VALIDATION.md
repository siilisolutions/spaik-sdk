## Runtime decision

A fresh Python 3.10 validation exposed missing model callbacks in upstream async agent execution, producing an empty transcript. Spaik 1.0 therefore requires Python 3.11+, updates CI/examples/templates accordingly, and removes the previous loop compatibility workaround. See [LangGraph's async context-propagation requirements](https://github.com/langchain-ai/docs/blob/main/src/oss/langgraph/streaming.mdx). This is a documented 1.0 break.

Deprecated coding-agent and workflow sources are removed; final pinned releases are published from main. There is no legacy wire-protocol adapter in 1.0.

## Reproduce

```sh
cd packages/agent-sdk
uv sync --all-extras --dev --locked
uv run --no-sync python -m pytest tests --no-cov
make lint
make typecheck
cd ../..
bun install --frozen-lockfile
bun run build:packages
packages/agent-sdk/.venv/bin/python scripts/generate_ag_ui_fixture.py
bun test packages/agent-sdk-hooks/tests
bunx playwright test
uv build --project packages/agent-sdk --out-dir /tmp/spaik-candidate
python scripts/validate_npm_artifacts.py --dist /tmp/spaik-candidate
```

The unified release workflow repeats these checks, validates installed npm tarballs, and publishes those artifacts. Stable versions must be rebuilt from the validated source with stable metadata and retested; RC artifacts cannot simply be relabeled.
